# Proposal

## Why

需要一个在自己电脑上运行的打字练习网站，既能练习中英文文章，也能从零学习字母的键盘位置和标准指法。通过循序渐进的关卡与可持续保存的成绩，让练习能够接续进行，并看见准确率和速度的变化。

## What Changes

- 新建基于 Python Flask 的本地个人网站，提供中文界面，通过浏览器使用。
- 提供全文练习和限时练习，支持中文、英文、内置文章及用户粘贴的文本，显示逐字反馈、速度、准确率和用时。
- 新增标准 QWERTY 键盘关卡，从 F/J 定位与基准行逐步扩展到全部 26 个字母，再进入混合及单词练习。
- 关卡中显示虚拟键盘、目标按键和推荐手指；完成本关且准确率达到 95% 后解锁下一关，不设速度门槛。
- 用 SQLite 保存关卡进度和历次练习成绩，关闭网站或重启 Python 后仍可继续练习。

## Capabilities

### New Capabilities

- `typing-practice`: 中英文素材选择、全文与限时练习、输入反馈及成绩统计。
- `keyboard-lessons`: 渐进字母课程、键位与指法提示、准确率通关和顺序解锁。
- `practice-records`: 本地成绩持久化、关卡进度恢复及历史成绩查看。

### Modified Capabilities

无。当前项目没有现有业务代码或已发布的功能规格。

## Impact

- 应用结构：预计新增 Flask 应用包、HTML 模板、CSS/JavaScript、文章与课程数据，以及相应验证和启动说明。
- 数据接口：新增素材、课程、练习结果提交、历史成绩及关卡进度接口，具体契约记录在技术设计中。
- 依赖：Flask；数据库通过 Python 的 `sqlite3` 使用 SQLite；浏览器交互采用原生 HTML/CSS/JavaScript。
- 本地数据：数据库放在应用实例目录，不随每次启动重建。
- 范围：个人电脑上的单一练习者，不包含注册登录、排行榜、教师管理、公网部署或云端同步。
