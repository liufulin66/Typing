# Spec Delta

## Purpose

在个人电脑上持续保存打字练习成绩和课程通过情况，使用户关闭浏览器或重启应用后仍能接续练习、复习已开放关卡，并通过清楚的历史记录了解不同语言与模式下的练习结果。

## ADDED Requirements

### Requirement: 保存完成练习

系统 SHALL 为有字符尝试且正常结算的全文、限时和关卡练习保存一条本地成绩，包括完成时间、模式、语言、素材或关卡名称、用时、正确字符数、错误尝试数、准确率、速度及其单位；关卡成绩还应记录是否通过。

#### Scenario: 保存未通过的关卡成绩
- **WHEN** 用户完成一关但准确率低于 95%
- **THEN** 历史中保存本次成绩并标明未通过，下一关不被解锁

#### Scenario: 保存文章练习成绩
- **WHEN** 用户完成一篇自定义英文文章的全文练习
- **THEN** 系统保存模式、语言、素材名称和成绩指标，速度单位为 WPM

### Requirement: 重启后恢复进度

系统 SHALL 在关闭浏览器或重启应用后保留全部已保存成绩，并恢复已经获得的关卡通关和解锁状态；常规启动不得清空数据库。

#### Scenario: 重新启动应用
- **WHEN** 用户已通过前两关、关闭应用并重新打开
- **THEN** 前两关仍显示已通过，第三关可练习，先前成绩仍可查看

### Requirement: 历史成绩展示

系统 SHALL 提供按完成时间从新到旧排列的历史列表，显示每条记录的模式、语言、名称、速度及单位、准确率和用时，关卡记录额外显示通过状态；首次使用时显示可理解的空状态和练习入口。

#### Scenario: 查看混合语言成绩
- **WHEN** 历史中包含中文全文练习、英文限时练习和关卡成绩
- **THEN** 页面清楚区分三者，中文速度使用字符/分钟，英文和字母关卡速度使用 WPM

#### Scenario: 尚无成绩
- **WHEN** 用户在首次完成练习之前打开历史页面
- **THEN** 页面说明尚无练习记录，并提供开始练习的入口

### Requirement: 重复提交不重复记分

系统 SHALL 对同一次练习结算只保存一条成绩。用户因重试、刷新或响应丢失而再次提交相同结果时，系统返回原保存结果，不重复创建记录或推进多个关卡。

#### Scenario: 保存响应丢失后重试
- **WHEN** 一次练习已成功保存，但用户因没有收到响应而再次提交相同结果
- **THEN** 历史中仍只有一条对应成绩，系统返回相同的保存状态和解锁结果

### Requirement: 保存状态与解锁一致

系统 SHALL 只在成绩持久保存成功后确认新的关卡通过和解锁；保存失败时，页面保留本次结算结果、显示失败原因并提供重试，不提前展示成功解锁。

#### Scenario: 保存失败
- **WHEN** 一次达到 95% 的关卡成绩因本地保存错误未能写入
- **THEN** 页面仍显示本次成绩和重试保存入口，下一关暂不开放，已有进度不受影响

### Requirement: 结果校验

系统 SHALL 校验结果属于有效练习，并依据统计数据计算准确率、速度和关卡是否通过；结果请求中直接声称通过、跳关或包含负数及矛盾计数时，不得据此更新进度。

#### Scenario: 直接声称通过
- **WHEN** 结果请求声称通过关卡，但正确尝试数与总尝试数计算出的准确率低于 95%
- **THEN** 系统不能将本关标记为通过，也不能解锁下一关

#### Scenario: 提交无效计数
- **WHEN** 结果请求包含负用时、正确尝试数大于总尝试数，或无法识别的练习标识
- **THEN** 系统返回明确错误，且不新增成绩或改变关卡进度
