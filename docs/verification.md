# 实施验证记录

日期：2026-10-21。变更：`add-python-typing-practice`。

## 环境与数据

- 项目独立环境：Python 3.12.14、Flask 3.1.3；运行依赖为 Flask，数据库由标准库 sqlite3 访问。
- 交付服务：`http://127.0.0.1:5000`，个人数据库为 `instance/typing.sqlite3`。
- 自动化和浏览器验收使用 `.tmp/tests/`、`.tmp/browser.sqlite3` 等独立数据，不清空或写入个人成绩。
- 界面交互验证使用 ChatGPT 内置浏览器。真实拼音输入法由用户按本机 Edge/Chrome 验收步骤测试，并反馈“没有问题”；具体浏览器产品及输入法名称未提供。

## 修复的验证问题

- 修正 Windows 注册表把 `.mjs` 识别为纯文本的情况，明确提供 JavaScript MIME 类型。
- 课程内容检查发现 Q/P 关卡的示例单词过早使用 T，已改为本关允许的字母组合。
- 已保存成绩刷新后使用冻结的服务端统计，切换标签页不会被空的本次输入计数覆盖。
- 对超大用时整数返回参数错误，避免数值转换溢出。

用户输入法反馈按实际提供的信息记录；未推断具体浏览器版本或输入法品牌。所有 16 关的自动键入成绩仅存在独立验收数据库中。
